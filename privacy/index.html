隐私政策

最后更新：2026-11-03

我们尽可能少地收集信息。运行检测无需注册账号，不设置 Cookie，也不使用广告追踪。llms.txt 工具页、调查报告、常见问题和旧版指南页使用自托管的 Umami 统计访问量，它不设置 Cookie，也不识别个人身份。

当你检测一个域名时

  • 我们的服务器会请求该域名的公开文件：robots.txt、llms.txt 和首页。这些请求由我们发出，而不是由你的浏览器发出。
  • 我们不保存你检测的域名，也不保存你的 IP 地址。你的 IP 地址只会被短暂用于请求限速，随后即被丢弃。
  • 每个检测结果以域名为键缓存约五分钟，以免重复检测再次访问该网站。报告的分享图片最多缓存一小时。

当你加入早期体验名单或联系我们时

  • 我们会保存你填写的邮箱地址、方案和网站，你发送的留言（如有），以及请求来源的国家或地区（由我们的托管服务商提供）。我们不保存你的 IP 地址。
  • 这些信息仅用于在你的账号就绪时通知你，以及回复你。我们不会出售这些信息，也不会将其用于营销或分享给他人。
  • 如需删除你的信息，请用同一邮箱通过联系表单提交请求。我们会在 30 天内删除。

当你开启监控时

  • 我们会保存你的邮箱、你要求监控的网站、语言，以及最近一次复测的摘要（三项评级和哪些 AI 爬虫被拦）。我们不保存你的 IP 地址。
  • 如果你没有确认，这条请求会在两天后删除。
  • 只有在你点了确认邮件里的链接之后，监控才会开始。邮箱只用来发这个网站的提醒。
  • 每封提醒邮件都有“停止监控”链接。停止后，该网站、它的复测摘要以及与你邮箱的关联会立即删除。
  • 复测和普通检测走同样的流程，必要时也会经由我们自己的服务器发出。

服务提供商

本站运行在 Cloudflare 上（托管、缓存和存储）。当某个网站屏蔽 Cloudflare 的网络时，部分检测会经由我们自己的服务器发出。Cloudflare 依据其隐私政策处理请求。确认邮件和提醒邮件通过 Resend 发送。

变更

如果本政策有变更，我们会更新页面顶部的日期。如果开始收集新的信息，我们会先在这里说明。
