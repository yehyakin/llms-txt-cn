    部署指南
    
    
    文件生成后，三步上线。核心就一条：让 https://你的域名/llms.txt 在浏览器里能直接看到纯文本
    
    
    
      
    
        
    WordPress / 虚拟主机
    
        
      
          
    • 主机面板 → 文件管理器 → 进入 public_html
      • 
          
    • 上传 llms.txt（文件名全小写）
      • 
          
    • 或用 Yoast SEO / AIOSEO 插件一键生成，自动随文章更新
      • 
        
    
      
    
      
    
        
    Vercel / Next.js / 静态站
    
        
      
          
    • 把 llms.txt 放进 public/ 目录
      • 
          
    • 重新部署，访问 /llms.txt 确认
      • 
          
    • Hugo / Hexo 同理：放进 static/ 目录
      • 
        
    
      
    
      
    
        
    自有服务器（Nginx / Caddy）
    
        
      
          
    • 放到网站根目录，与首页同级
      • 
          
    • 确认返回 Content-Type: text/plain 而非 HTML
      • 
          
    • 别让 WAF 把它当成可疑请求拦掉
      • 
        
    
      
    
      
    
        
    上线后复查清单
    
        
      
          
    • 浏览器打开 /llms.txt，看到的是文本不是网页
      • 
          
    • 随机点开 3–5 个链接，确认都能访问、不是 404
      • 
          
    • 改版或迁移后重新跑一遍校验（路由变了链接最容易挂）
      • 
          
    • robots.txt 确认没有误伤想开放的 AI 爬虫
      • 
        
    
      
    
    
    
  
    

  
  
    
    
    规范速览
    
    
    依据 llmstxt.org v2（2026-08）。校验器的每条结论都能在这里找到依据
    
    
    
      
    
        
    必须
    
        
      
          
    • # 站点名 是唯一必填章节，且只能有一个
      • 
          
    • 顺序固定：H1 → 摘要 → 详情段 → H2 分组
      • 
          
    • 每项是一个 Markdown 链接 [名称](URL)，名称不能为空
      • 
          
    • 文件可放根目录或子路径（如 /docs/llms.txt）
      • 
        
    
      
    
      
    
        
    推荐
    
        
      
          
    • H1 后跟 > 引用块写一句话摘要
      • 
          
    • 链接用 https:// 绝对地址，并配 : 描述
      • 
          
    • 名为 Optional 的分组会被 AI 跳过，别放核心链接
      • 
          
    • v2 新增发现机制：rel=describedby 指向 llms.txt
      •
