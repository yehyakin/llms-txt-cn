# llms-txt-cn

面向中文站长的 llms.txt 生成器 + 校验器。

`llms.txt`（[llmstxt.org](https://llmstxt.org) 规范）是放在网站根目录的 Markdown 文件，帮助 AI 模型快速理解网站结构，是 AI 搜索时代（GEO）的基础卫生项。本项目提供中文界面的生成与校验工具：纯前端、零后端，文件不出浏览器。

## 功能

### v1（开发中）

- **生成器**：填写站点名、简介、关键页面 → 生成符合规范的 `llms.txt` → 一键复制 / 下载
- **校验器**：粘贴已有的 `llms.txt` → 校验 H1、链接格式、URL 有效性 → 0–100 AI 就绪度评分 + 中文改进建议

### 路线图

- v1.1：五维评分模型（合规 30 / 内容 25 / 链接 25 / 可发现性 10 / 体积效率 10）
- v2：sitemap 导入、Hexo / Hugo / VuePress 构建插件、中文 AI 引擎可见性监测

## 使用

纯静态页面，直接用浏览器打开 `index.html` 即可（或部署到任意静态托管）。

## 评分口径

评分是"文件质量分"，不是"AI 引用保证"。截至 2026 年，没有主流 LLM 厂商公开承诺系统性消费 `llms.txt`，请把它当作卫生项，而非排名手段。
