# llms-txt-cn

面向中文站长的 llms.txt 生成、检查与部署助手。

`llms.txt`（[llmstxt.org](https://llmstxt.org) 规范）是放在网站根目录的 Markdown 文件，帮助 AI 模型快速理解网站结构，是 AI 搜索时代（GEO）的基础卫生项。本项目提供中文界面的生成、校验与部署工具：纯前端、零后端，文件不出浏览器。

线上地址：https://cetxt.com

## 功能

- **生成器**：填写站点名、简介、分组链接 → 生成符合规范的 `llms.txt` → 实时预览、一键复制 / 下载（含博客、企业官网、文档站模板）
- **校验器**：粘贴或上传已有的 `llms.txt`（支持 UTF-8 / GBK / Big5）→ 按规范做 28 项确定性检查 → 0–100 文件质量分 + 每条问题的中文修复建议
- **部署指南**：WordPress、Vercel、Nginx/Caddy 的上线步骤与复查清单

## 评分口径

四维加权：H1 标题 30 / 摘要 20 / H2 分组 30 / 链接质量 20；有错误时总分封顶 59。

评分是"文件质量分"，不是"AI 引用保证"。截至 2026 年，没有主流 LLM 厂商公开承诺系统性消费 `llms.txt`，请把它当作卫生项，而非排名手段。

## 现状抽样（2026-10）

抽样 100 个中文独立站点：仅 19% 在根目录有真正的 `llms.txt`，独立博客圈覆盖率约 7%；14% 的站掉进 SPA 陷阱（`/llms.txt` 返回 200 的 HTML）。中文站长缺的不是意愿，是顺手的中文工具——这正是本项目存在的理由。

## 使用

纯静态页面，直接用浏览器打开 `index.html` 即可（或部署到任意静态托管）。
