Amzn-SearchBot

OperatorAmazon
PurposeSearch
Follows robots.txtYes
SourceOfficial docs ↗

Amazon's search crawler for experiences such as Alexa. Amazon says it doesn't crawl content for generative AI model training.

What happens if you block it

Your content can't appear in Amazon search experiences such as Alexa.

Our take

Allow it if you want to be found through Alexa and Amazon search.

robots.txt

To block it:

User-agent: Amzn-SearchBot
Disallow: /

To allow it explicitly (useful when a wider rule blocks other bots):

User-agent: Amzn-SearchBot
Allow: /

The operator's own words

Amzn-SearchBot does not crawl content for generative AI model training.Amazon documentation, checked 2026-10-31

robots.txt allows it, but is it really getting through?

A firewall or CDN rule can reject Amzn-SearchBot even when robots.txt welcomes it, and nothing in your CMS shows it. Our check sends a live request as Amzn-SearchBot alongside a normal browser and a Googlebot control, so a bot-verification rule isn't mistaken for a block.
