Perplexity-User

OperatorPerplexity
PurposeUser-triggered
Follows robots.txtGenerally no
SourceOfficial docs ↗

Fetches made when a Perplexity user asks a question that needs your page.

What happens if you block it

Perplexity says this fetcher generally ignores robots.txt because a user requested it. Only a firewall rule actually stops it.

Our take

Leave it allowed unless you have a reason to block user-directed fetches.

robots.txt

To block it:

User-agent: Perplexity-User
Disallow: /

To allow it explicitly (useful when a wider rule blocks other bots):

User-agent: Perplexity-User
Allow: /

The operator's own words

Since a user requested the fetch, this fetcher generally ignores robots.txt rules.Perplexity documentation, checked 2026-10-31

robots.txt allows it, but is it really getting through?

A firewall or CDN rule can reject Perplexity-User even when robots.txt welcomes it, and nothing in your CMS shows it. Our check sends a live request as Perplexity-User alongside a normal browser and a Googlebot control, so a bot-verification rule isn't mistaken for a block.
