Baidu's search crawler. It follows robots.txt.

What happens if you block it

Your pages can't be found on Baidu or on any search engine that uses Baidu's search service.

Our take

Keep it allowed if you want traffic from China.

robots.txt

To block it:

User-agent: Baiduspider
Disallow: /

To allow it explicitly (useful when a wider rule blocks other bots):

User-agent: Baiduspider
Allow: /

The operator's own words

Baiduspider遵守互联网robots协议……禁止Baiduspider访问您的网站，将使您的网站上的网页，在百度搜索引擎以及所有百度提供搜索引擎服务的搜索引擎中无法被搜索到。百度 documentation, checked 2026-10-31

robots.txt allows it, but is it really getting through?
