VAKSEL Lab

Last run 2026-11-02 · rules 2026-11-02.2

20 public test sites. Each one changes exactly one thing from the control, so you can see whether an AI visibility tool notices. Point any tool at them, ours included.

How to use it

  • Run your tool on baseline-lab.vaksel.com first. It should come back clean.
  • Then run it on the others. Each row says what changed and what a correct tool should report.
  • The firewall sites decide by user agent, the way most real firewalls do. They answer the same way to every IP address.

What it caught in our own engine

Our first run, on the first 19 sites, matched 3. The lab found four bugs, now fixed:

  • Huawei’s PetalBot wasn’t in our crawler list, so a site that blocked everyone in robots.txt was graded B instead of C. The same bug hid a robots.txt 503.
  • An X-Robots-Tag: noindex header was missed when we fetched through our fallback server.
  • When a site refused our direct request, its sitemap was reported missing, because the sitemap check had no fallback server.
  • A page that merely mentioned “Just a moment” was mistaken for a challenge page. We changed the test site; real challenge detection still uses page size.

Limits

The sites simulate common setups. They don’t reproduce IP-based verification by real vendors, JavaScript challenges that need a browser, or rate limits. Expected grades follow our published rules; another tool may use different labels and still be right.
