Perplexity-User

运营方Perplexity
用途用户触发
遵守 robots.txt一般不遵守
来源官方文档 ↗

用户在 Perplexity 提问时代为访问页面；官方称一般忽略 robots.txt。

屏蔽后会怎样

官方说明它一般忽略 robots.txt，写禁止规则大概率拦不住，需要 WAF 层处理。

robots.txt 写法

屏蔽：

User-agent: Perplexity-User
Disallow: /

显式放行（当有更宽的规则拦了其他机器人时有用）：

User-agent: Perplexity-User
Allow: /

官方原文

Since a user requested the fetch, this fetcher generally ignores robots.txt rules.Perplexity 文档，核对于 2026-10-31

robots.txt 允许了，它就真能进来吗？

即使 robots.txt 欢迎 Perplexity-User，防火墙或 CDN 规则也可能拒绝它，而后台不会有任何提示。我们的检测会以 Perplexity-User 的身份实际请求，同时用浏览器和 Googlebot 做对照，避免把爬虫 IP 核验误判成拦截。
