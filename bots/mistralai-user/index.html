MistralAI-User

运营方Mistral AI
用途用户触发
遵守 robots.txt遵守
来源官方文档 ↗

用户在 Mistral 的助手里提问时按需访问网页并在回答中附上来源链接。官方说明它不做自动抓取，也不用于训练。

屏蔽后会怎样

Mistral 助手无法按用户请求打开你的页面，也就不会把你列为来源。

robots.txt 写法

屏蔽：

User-agent: MistralAI-User
Disallow: /

显式放行（当有更宽的规则拦了其他机器人时有用）：

User-agent: MistralAI-User
Allow: /

官方原文

When users ask Vibe a question, it may visit a web page to help answer and include a link to the source in its response. MistralAI-User governs which sites these user requests can be made to.Mistral AI 文档，核对于 2026-11-04

robots.txt 允许了，它就真能进来吗？

即使 robots.txt 欢迎 MistralAI-User，防火墙或 CDN 规则也可能拒绝它，而后台不会有任何提示。我们的检测会以 MistralAI-User 的身份实际请求，同时用浏览器和 Googlebot 做对照，避免把爬虫 IP 核验误判成拦截。
