最后更新：2026-11-01

使用检测服务

  • 请检测你拥有、管理或有正当理由查看的网站。不得使用本服务对网站进行压力测试、扫描或攻击。
  • 检测有频率限制。请勿通过自动化手段或多个网络绕过限制。

检测结果的含义

检测结果是我们在检测当时的最佳判断。我们从数据中心 IP 地址、以各爬虫的 user agent 发起测试，而不是从爬虫自己的网络发起，因此会验证爬虫 IP 地址的网站可能会以不同方式对待真实爬虫。正因如此，每个结果都会标注置信度。爬虫说明以各运营方截至所示日期的公开文档为准。

免责声明

本服务按“现状”提供，不作任何形式的保证。在法律允许的范围内，我们不对依据报告作出的决定，或因使用本服务产生的任何损失承担责任。

付费方案

监测方案目前处于抢先体验阶段。加入名单不代表你需要付费。付费方案开放时，我们会在你订阅前展示其条款和价格。

变更与联系
